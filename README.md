# NoiseReduction

Noise Reduction in Speech Signals Using Digital Filters (Adaptive Prediction)

## Overview
This project focuses on reducing background noise in speech signals using digital signal processing techniques. It combines FIR filtering and adaptive filtering to enhance speech clarity.

## Key Features
- FIR low-pass filtering for basic noise removal
- Adaptive filtering (LMS/RLS) for dynamic noise reduction
- Spectral techniques using FFT
- Improved speech intelligibility

## Tools & Technologies
- Python
- NumPy, SciPy
- Librosa, SoundFile
- Matplotlib

## Methodology
Noisy Input → Preprocessing → FIR Filter → Adaptive Filter → Output

## Dataset
NOIZEUS dataset (real-world noisy speech samples)

## Output
- Enhanced speech signal
- Improved SNR
- Visual analysis using FFT

## How to Run
1. Install dependencies
2. Run main.py
